# Корни

Трекер привычек с планированием на день, неделю, месяц и год. Тёплая палитра земли, шалфея и дерева, адаптивная верстка, локальное сохранение данных без регистрации.

## Запуск

Требуется Python 3. В каталоге проекта выполните `python3 -m http.server 3000 --bind 0.0.0.0` или `npm run dev`.

Проверка JavaScript: `npm run check` (Node.js). Установка пакетов не требуется. Стили и JavaScript встроены в `index.html`, чтобы сайт работал и в просмотрщиках, которые не отдают соседние файлы. После редактирования `style.css` или `app.js` выполните `npm run build` (или `python3 scripts/bundle.py`); `npm run dev` делает это автоматически.

Привычки повторяются в каждом соответствующем периоде; отметки выполнения и фокус сохраняются отдельно для каждой даты, недели, месяца или года. Серия — последовательные дни с хотя бы одной выполненной ежедневной привычкой. Данные сохраняются в localStorage текущего браузера и не синхронизируются между устройствами. Очистка данных браузера удаляет записи. Шрифты Google Fonts необязательны: доступны системные замены.
