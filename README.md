# Корни

Трекер привычек с планированием на день, неделю, месяц и год. Тёмная природная палитра, адаптивная верстка, локальное сохранение данных без регистрации.

## Запуск

Требуется Python 3. В каталоге проекта выполните `python3 -m http.server 3000 --bind 0.0.0.0` или `npm run dev`.

Проверка JavaScript: `npm run check` (Node.js). Установка пакетов не требуется. Стили и JavaScript встроены в `index.html`, чтобы сайт работал и в просмотрщиках, которые не отдают соседние файлы. После редактирования `style.css` или `app.js` выполните `npm run build` (или `python3 scripts/bundle.py`); `npm run dev` делает это автоматически.

Ежедневные привычки можно назначить на конкретные дни недели (до пяти в каждой зоне «Почва» и «Рост»). Изменение расписания и пауза действуют с текущего дня; прежние отметки сохраняются. Отчёты считают запланированные привычки и уже выполненные отметки, а будущие дни не входят в общий процент. Третья карточка показывает дни с прогрессом за последние семь дней вместо серии, которая обнуляется после пропуска. Удаление привычки стирает и историю её отметок после подтверждения.

Отметки выполнения и фокус сохраняются отдельно для каждой даты, недели, месяца или года. Данные хранятся в localStorage текущего браузера и не синхронизируются между устройствами. Очистка данных браузера удаляет записи. Шрифты Google Fonts необязательны: доступны системные замены.
